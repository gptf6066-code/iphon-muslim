# iPhon Muslim (Android)

Аппе, ки рӯй ва бадани одамонро дар экрани телефон худкор мепӯшонад —
дар YouTube, Instagram, Google, Галерея ва ҳар апп.

## Чӣ тавр APK гирифтан
1. Дар GitHub репозиторийи нав созед (масалан `iphon-muslim`).
2. Ҳамаи файлҳои ин папкаро (бо папкаи `.github`) ба он бор кунед.
3. Ба ҷадвали **Actions** равед → **Build APK** → интизор шавед (~5–8 дақ).
4. Дар поён **iphon-muslim-apk**-ро зеркашӣ кунед, zip-ро кушоед, `app-debug.apk`-ро ба телефон гузоред.

## Истифода
1. Аппро кушоед → «Фаъол кардан».
2. Иҷозати «Нишон додан болои дигар аппҳо»-ро диҳед.
3. Дар саволи сабти экран **«Тамоми экран»**-ро интихоб кунед → «Оғоз».
4. Аз Honor/MagicOS: Танзимот → Батарея → iPhon Muslim → «Идоракунии дастӣ», ҳама фаъол — то система онро набандад.
